### 11.2.1 邮件服务

**使用场景：**
- 密码重置
- 账号激活
- 系统通知

**集成方案：** Spring Mail

```java
@Configuration
public class MailConfig {
    
    @Bean
    public JavaMailSender javaMailSender() {
        JavaMailSenderImpl sender = new JavaMailSenderImpl();
        sender.setHost("smtp.example.com");
        sender.setPort(587);
        sender.setUsername("noreply@example.com");
        sender.setPassword("${MAIL_PASSWORD}");
        sender.setProtocol("smtp");
        
        Properties props = sender.getJavaMailProperties();
        props.put("mail.transport.protocol", "smtp");
        props.put("mail.smtp.auth", "true");
        props.put("mail.smtp.starttls.enable", "true");
        
        return sender;
    }
}
```

**发送服务：**
```java
@Service
public class EmailService {
    
    @Autowired
    private JavaMailSender mailSender;
    
    @Async
    public void sendPasswordResetEmail(String to, String resetToken) {
        String subject = "密码重置";
        String content = "请点击链接重置密码：" + 
            "http://example.com/reset?token=" + resetToken;
        
        SimpleMailMessage message = new SimpleMailMessage();
        message.setFrom("noreply@example.com");
        message.setTo(to);
        message.setSubject(subject);
        message.setText(content);
        
        mailSender.send(message);
    }
}
```

**配置：**
```yaml
spring:
  mail:
    host: smtp.example.com
    port: 587
    username: ${MAIL_USERNAME}
    password: ${MAIL_PASSWORD}
    properties:
      mail:
        smtp:
          auth: true
          starttls:
            enable: true
```

            return "OK".equals(response.getCode());
            
        } catch (Exception e) {
            LOGGER.error("发送短信失败", e);
            return false;
        }

### 11.2.3 对象存储 (OSS)

**使用场景：**
- 用户头像上传
- 文件附件存储
- 图片资源管理

**集成方案：** 阿里云 OSS / 腾讯云 COS

```java
@Service
public class OssService {
    
    @Value("${oss.endpoint}")
    private String endpoint;
    
    @Value("${oss.access-key-id}")
    private String accessKeyId;
    
    @Value("${oss.access-key-secret}")
    private String accessKeySecret;
    
    @Value("${oss.bucket-name}")
    private String bucketName;
    
    /**
     * 上传文件
     */
    public String uploadFile(MultipartFile file, String folder) {
        try {
            OSSClient ossClient = new OSSClient(endpoint, accessKeyId, accessKeySecret);
            
            // 生成文件名
            String fileName = folder + "/" + 
                UUID.randomUUID().toString().replace("-", "") + 
                getFileExtension(file.getOriginalFilename());
            
            ossClient.putObject(bucketName, fileName, file.getInputStream());
            
            // 返回访问 URL
            return "https://" + bucketName + "." + endpoint + "/" + fileName;
            
        } catch (Exception e) {
            LOGGER.error("文件上传失败", e);
            throw new BusinessException("文件上传失败");
        }
    }
    
    /**
     * 删除文件
     */
    public void deleteFile(String fileUrl) {
        // 提取文件名
        String fileName = extractFileName(fileUrl);
        
        OSSClient ossClient = new OSSClient(endpoint, accessKeyId, accessKeySecret);
        ossClient.deleteObject(bucketName, fileName);
    }
}
```

**配置：**
```yaml
oss:
  endpoint: oss-cn-hangzhou.aliyuncs.com
  access-key-id: ${OSS_ACCESS_KEY_ID}
  access-key-secret: ${OSS_ACCESS_KEY_SECRET}
  bucket-name: my-bucket
  # 文件大小限制
  max-file-size: 10MB
  # 超时配置
  timeout: 10000
```

## 11.3 超时与重试策略

### 11.3.1 超时配置

**RestTemplate 超时配置：**

```java
@Configuration
public class RestTemplateConfig {
    
    @Bean
    public RestTemplate restTemplate() {
        SimpleClientHttpRequestFactory factory = new SimpleClientHttpRequestFactory();
        
        // 连接超时：3 秒
        factory.setConnectTimeout(3000);
        
        // 读取超时：5 秒
        factory.setReadTimeout(5000);
        
        return new RestTemplate(factory);
    }
}
```

```yaml
feign:
  client:
    config:
      default:
        connectTimeout: 3000
        readTimeout: 5000
```

### 11.3.2 重试机制

**Spring Retry 配置：**

```java
@Service
public class ExternalService {
    
    @Retryable(
        value = {RemoteAccessException.class},
        maxAttempts = 3,
        backoff = @Backoff(delay = 1000, multiplier = 2)
    )
    public String callExternalService() {
        // 调用外部服务
        return restTemplate.getForObject(url, String.class);
    }
    
    @Recover
    public String recover(RemoteAccessException e) {
        // 重试失败后的处理
        LOGGER.error("外部服务调用失败", e);
        return null;
    }
}
```

**配置：**
```yaml
spring:
  retry:
    max-attempts: 3
    max-backoff: 10000
    initial-backoff: 1000
    multiplier: 2.0
```

## 11.4 熔断降级

### 11.4.1 熔断器模式

**使用 Resilience4j：**

```java
@Service
public class CircuitBreakerService {
    
    @CircuitBreaker(name = "externalService", fallbackMethod = "fallback")
    public String callExternalService() {
        return restTemplate.getForObject(url, String.class);
    }
    
    public String fallback(Exception e) {
        // 降级处理
        return "服务暂时不可用";
    }
}
```

**配置：**
```yaml
resilience4j:
  circuitbreaker:
    instances:
      externalService:
        slidingWindowSize: 10
        failureRateThreshold: 50
        waitDurationInOpenState: 10000
        permittedNumberOfCallsInHalfOpenState: 3
```

### 11.4.2 降级策略

| 场景 | 降级策略 |
|------|---------|
| 超时 | 返回默认值/缓存数据 |
| 错误 | 返回错误提示 |
| 熔断 | 快速失败，不调用 |

## 11.5 接口幂等性

### 11.5.1 幂等性设计

**Token 机制：**

```java
@Service
public class IdempotentService {
    
    /**
     * 生成幂等 Token
     */
    public String generateToken(String bizKey) {
        String token = UUID.randomUUID().toString();
        String key = "idempotent:" + bizKey;
        redisTemplate.opsForValue().set(key, token, 30, TimeUnit.MINUTES);
        return token;
    }
    
    /**
     * 验证并消耗 Token
     */
    public boolean verifyToken(String bizKey, String token) {
        String key = "idempotent:" + bizKey;
        String cachedToken = redisTemplate.opsForValue().get(key);
        
        if (cachedToken == null) {
            return false; // Token 已过期或已被消耗
        }
        
        // 使用 Lua 脚本保证原子性
        String luaScript = 
            "if redis.call('get', KEYS[1]) == ARGV[1] then " +
            "  return redis.call('del', KEYS[1]) " +
            "else " +
            "  return 0 " +
            "end";
        
        Long result = redisTemplate.execute(
            new DefaultRedisScript<>(luaScript, Long.class),
            Collections.singletonList(key),
            token
        );
        
        return result == 1;
    }
}
```

**使用注解：**

```java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface Idempotent {
    String key() default "";
    long expire() default 30; // 秒
}

@Aspect
@Component
public class IdempotentAspect {
    
    @Around("@annotation(idempotent)")
    public Object around(ProceedingJoinPoint point, Idempotent idempotent) {
        String key = idempotent.key();
        String token = getTokenFromHeader();
        
        if (!idempotentService.verifyToken(key, token)) {
            throw new BusinessException("重复提交");
        }
        
        return point.proceed();
    }
}
```

## 11.6 监控与告警

### 11.6.1 调用监控

**记录调用耗时：**

```java
@Aspect
@Component
public class ExternalServiceMonitor {
    
    @Around("execution(* *..ExternalService.*(..))")
    public Object monitor(ProceedingJoinPoint point) throws Throwable {
        long start = System.currentTimeMillis();
        String method = point.getSignature().getName();
        
        try {
            Object result = point.proceed();
            long cost = System.currentTimeMillis() - start;
            
            if (cost > 1000) {
                LOGGER.warn("外部服务调用超时：{}, cost: {}ms", method, cost);
            }
            
            return result;
            
        } catch (Exception e) {
            LOGGER.error("外部服务调用异常：{}", method, e);
            throw e;
        }
    }
}
```

### 11.6.2 告警规则

| 指标 | 阈值 | 告警级别 |
|------|------|---------|
| 调用失败率 | > 5% | 警告 |
| 调用失败率 | > 20% | 严重 |
| 平均耗时 | > 2s | 警告 |
| 熔断触发 | 任意 | 严重 |

### 11.7.2 请求签名

```java
public class SignUtil {
    
    /**
     * 生成请求签名
     */
    public static String generateSign(Map<String, String> params, String secret) {
        // 参数排序
        List<String> keys = new ArrayList<>(params.keySet());
        Collections.sort(keys);
        
        // 拼接字符串
        StringBuilder sb = new StringBuilder();
        for (String key : keys) {
            sb.append(key).append("=").append(params.get(key)).append("&");
        }
        sb.append("key=").append(secret);
        
        // MD5 签名
        return MD5.md5(sb.toString());
    }
}
```
