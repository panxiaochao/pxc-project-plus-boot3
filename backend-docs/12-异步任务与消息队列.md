## 12.1 异步任务概述

### 12.1.1 当前实现

本项目使用 **Spring @Async** 实现异步任务，**未使用消息队列**（RabbitMQ/Kafka）。

**已使用的异步场景：**
- 字典数据缓存刷新
- 系统参数缓存刷新
- 日志异步记录

## 12.2 异步任务配置

### 12.2.1 启用异步

**配置类：**

```java
@Configuration
@EnableAsync
public class AsyncConfig {
    
    @Bean(name = "taskExecutor")
    public Executor taskExecutor() {
        ThreadPoolTaskExecutor executor = new ThreadPoolTaskExecutor();
        
        // 核心线程数
        executor.setCorePoolSize(5);
        
        // 最大线程数
        executor.setMaxPoolSize(20);
        
        // 队列容量
        executor.setQueueCapacity(100);
        
        // 线程空闲时间
        executor.setKeepAliveSeconds(60);
        
        // 线程前缀名称
        executor.setThreadNamePrefix("async-task-");
        
        // 拒绝策略：调用者运行
        executor.setRejectedExecutionHandler(new ThreadPoolExecutor.CallerRunsPolicy());
        
        // 等待所有任务结束后再关闭线程池
        executor.setWaitForTasksToCompleteOnShutdown(true);
        
        // 等待时间
        executor.setAwaitTerminationSeconds(60);
        
        executor.initialize();
        
        return executor;
    }
}
```

### 12.2.2 配置参数说明

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| corePoolSize | CPU 核心数 * 2 | 核心线程数 |
| maxPoolSize | CPU 核心数 * 4 | 最大线程数 |
| queueCapacity | 100-500 | 队列容量 |
| keepAliveSeconds | 60 | 空闲线程存活时间 |
| rejectedExecutionHandler | CallerRunsPolicy | 拒绝策略 |

**拒绝策略说明：**
- `CallerRunsPolicy`：调用者线程执行（降级）
- `AbortPolicy`：抛出异常（默认）
- `DiscardPolicy`：直接丢弃
- `DiscardOldestPolicy`：丢弃最老任务

## 12.3 异步任务使用

### 12.3.1 @Async 注解

**字典缓存刷新：** `SysDictItemAppService.java`

```java
@Service
public class SysDictItemAppService {
    
    /**
     * 异步刷新字典缓存
     */
    @Async("taskExecutor")
    public void refreshDictCache() {
        // 从数据库加载字典数据
        List<SysDictItemBO> dictItems = sysDictItemService.listAll();
        
        // 转换为 Map
        Map<String, List<SysDictItemBO>> dictMap = dictItems.stream()
            .collect(Collectors.groupingBy(SysDictItemBO::getDictCode));
        
        // 存入 Redis
        dictMap.forEach((code, items) -> {
            String key = GlobalRedisConstant.KEY_SYS_DICT + code;
            redisTemplate.opsForValue().set(key, items, 30, TimeUnit.MINUTES);
        });
        
        LOGGER.info("字典缓存刷新完成，共{}条", dictItems.size());
    }
}
```

**系统参数缓存刷新：** `SysParamAppService.java`

```java
@Service
public class SysParamAppService {
    
    @Async("taskExecutor")
    public void refreshParamCache() {
        // 加载系统参数
        List<SysParamBO> params = sysParamService.listAll();
        
        // 存入 Redis Hash
        RMap<String, String> paramMap = redissonClient.getMap("sys:param");
        params.forEach(param -> {
            paramMap.put(param.getParamCode(), param.getParamValue());
        });
        
        LOGGER.info("系统参数缓存刷新完成");
    }
}
```

### 12.3.2 异步任务调用

**同步调用（等待结果）：**

```java
@Service
public class ReportService {
    
    @Autowired
    private ReportAsyncService reportAsyncService;
    
    public void generateReport() {
        // 异步生成报告
        CompletableFuture<Report> future = reportAsyncService.generateReportAsync();
        
        // 继续其他业务
        doOtherThings();
        
        // 等待结果（可选）
        try {
            Report report = future.get(30, TimeUnit.SECONDS);
            sendReport(report);
        } catch (Exception e) {
            LOGGER.error("报告生成失败", e);
        }
    }
}
```

**完全异步（不等待结果）：**

```java
@Service
public class LogService {
    
    @Autowired
    private LogAsyncService logAsyncService;
    
    public void recordOperation(Operation operation) {
        // 记录操作日志（异步）
        logAsyncService.saveLogAsync(operation);
        
        // 立即返回，不等待
    }
}
```

### 12.4.2 定时任务配置

**定时任务实体：** `SysJobPO`

| 字段 | 说明 |
|------|------|
| job_name | 任务名称 |
| job_group | 任务分组 |
| invoke_target | 调用目标 |
| cron_expression | Cron 表达式 |
| misfire_policy | 错过执行策略 |
| concurrent | 是否并发 |
| status | 状态 |

### 12.4.3 Cron 表达式

**语法：** `秒 分 时 日 月 周`

**示例：**

| 表达式 | 说明 |
|--------|------|
| `0 0 12 * * ?` | 每天中午 12 点执行 |
| `0 15 10 ? * MON-FRI` | 工作日每天上午 10:15 执行 |
| `0 0/5 * * * ?` | 每 5 分钟执行一次 |
| `0 0 1 1 * ?` | 每月 1 号凌晨 1 点执行 |
| `0 0 1 1/2 * ?` | 每两个月 1 号凌晨 1 点执行 |

### 12.4.4 定时任务实现

```java
@Component
public class ScheduledTasks {
    
    private static final Logger LOG = LoggerFactory.getLogger(ScheduledTasks.class);
    
    /**
     * 每小时清理过期日志
     */
    @Scheduled(cron = "0 0 * * * ?")
    public void cleanExpiredLogs() {
        LOG.info("开始清理过期日志");
        
        // 清理 30 天前的登录日志
        LocalDateTime threshold = LocalDateTime.now().minusDays(30);
        sysLogLoginService.deleteBefore(threshold);
        
        // 清理 90 天前的操作日志
        sysLogOperateService.deleteBefore(threshold.plusDays(60));
        
        LOG.info("过期日志清理完成");
    }
    
    /**
     * 每天凌晨 2 点备份数据
     */
    @Scheduled(cron = "0 0 2 * * ?")
    public void backupData() {
        LOG.info("开始数据备份");
        
        // 执行备份逻辑
        // ...
        
        LOG.info("数据备份完成");
    }
    
    /**
     * 每分钟检查系统健康
     */
    @Scheduled(fixedRate = 60000)
    public void checkSystemHealth() {
        // 检查数据库连接
        // 检查 Redis 连接
        // 检查磁盘空间
    }
}
```

### 12.4.5 动态定时任务

**基于数据库的定时任务管理：**

```java
@Service
public class DynamicJobService {
    
    @Autowired
    private Scheduler scheduler;
    
    /**
     * 添加定时任务
     */
    public void addJob(SysJobBO job) {
        try {
            JobKey jobKey = JobKey.jobKey(job.getJobName(), job.getJobGroup());
            
            // 检查是否已存在
            if (scheduler.checkExists(jobKey)) {
                scheduler.deleteJob(jobKey);
            }
            
            // 创建 JobDetail
            JobDetail jobDetail = JobBuilder.newJob(ExecuteJob.class)
                .withIdentity(jobKey)
                .build();
            
            // 创建 Trigger
            CronScheduleBuilder scheduleBuilder = CronScheduleBuilder
                .cronSchedule(job.getCronExpression());
            
            CronTrigger trigger = TriggerBuilder.newTrigger()
                .withIdentity(TriggerKey.triggerKey(job.getJobName() + "_trigger", job.getJobGroup()))
                .withSchedule(scheduleBuilder)
                .build();
            
            // 调度执行
            scheduler.scheduleJob(jobDetail, trigger);
            
            if (!job.getStatus().equals("1")) {
                scheduler.pauseJob(jobKey);
            }
            
        } catch (SchedulerException e) {
            throw new BusinessException("添加定时任务失败", e);
        }
    }
    
    /**
     * 执行任务目标
     */
    public static class ExecuteJob implements Job {
        @Override
        public void execute(JobExecutionContext context) {
            JobDataMap dataMap = context.getMergedJobDataMap();
            String invokeTarget = dataMap.getString("invokeTarget");
            
            // 使用 Spring 容器执行
            BeanUtil.invoke(invokeTarget);
        }
    }
}
```

## 12.5 事件驱动

### 12.5.1 Spring 事件机制

**定义事件：**

```java
public class UserCreatedEvent extends ApplicationEvent {
    
    private final Integer userId;
    private final String username;
    
    public UserCreatedEvent(Object source, Integer userId, String username) {
        super(source);
        this.userId = userId;
        this.username = username;
    }
    
    public Integer getUserId() { return userId; }
    public String getUsername() { return username; }
}
```

**发布事件：**

```java
@Service
public class UserService {
    
    @Autowired
    private ApplicationEventPublisher eventPublisher;
    
    public SysUserBO save(SysUserBO user) {
        // 保存用户
        user = userRepository.save(user);
        
        // 发布事件
        eventPublisher.publishEvent(new UserCreatedEvent(this, user.getId(), user.getLoginName()));
        
        return user;
    }
}
```

**监听事件：**

```java
@Component
public class UserCreatedEventListener {
    
    /**
     * 同步监听

    public void handleUserCreated(UserCreatedEvent event) {
```

## 12.6 消息队列（未来规划）

### 12.6.1 选型建议

| MQ | 优点 | 缺点 | 适用场景 |
|----|------|------|---------|
| **RabbitMQ** | 延迟低、可靠性高 | 吞吐量较低 | 金融、订单 |
| **Kafka** | 吞吐量高、可扩展 | 延迟较高 | 日志、大数据 |
| **RocketMQ** | 阿里出品、功能全 | 运维复杂 | 电商、交易 |

### 12.6.2 RabbitMQ 集成示例

**配置：**

```yaml
spring:
  rabbitmq:
    host: ${RABBITMQ_HOST:localhost}
    port: ${RABBITMQ_PORT:5672}
    username: ${RABBITMQ_USERNAME:guest}
    password: ${RABBITMQ_PASSWORD:guest}
    listener:
      simple:
        acknowledge-mode: manual  # 手动确认
        concurrency: 5            # 最小消费数
        max-concurrency: 10       # 最大消费数
        retry:
          enabled: true
          max-attempts: 3
```

**生产者：**

```java
@Service
public class MessageProducer {
    
    @Autowired
    private RabbitTemplate rabbitTemplate;
    
    /**
     * 发送消息
     */
    public void sendMessage(String queueName, Object message) {
        rabbitTemplate.convertAndSend(queueName, message);
    }
    
    /**
     * 发送消息（带确认回调）
     */
    public void sendMessageWithConfirm(String queueName, Object message) {
        CorrelationData correlationData = new CorrelationData(UUID.randomUUID().toString());
        
        rabbitTemplate.convertAndSend(queueName, message, correlationData);
        
        // 注册回调
        rabbitTemplate.setConfirmCallback((correlation, ack, cause) -> {
            if (!ack) {
                LOGGER.error("消息发送失败：{}", cause);
            }
        });
    }
}
```

**消费者：**

```java
@Component
public class MessageConsumer {
    
    /**
     * 监听队列
     */

    public void handleUserCreated(UserCreatedMessage message) {
        try {
            // 处理消息

        } catch (Exception e) {
            LOGGER.error("处理消息失败", e);
            
            // 拒绝消息（重试）

        }
    }
}
```

### 12.6.3 消息幂等性

**幂等键设计：**

```java
public class MessageProcessor {
    
    /**
     * 处理消息（幂等）
     */
    @RabbitListener(queues = "order.created")
    public void handleOrder(OrderMessage message) {
        String messageId = message.getMessageId();
        
        // 检查是否已处理
        if (redisTemplate.hasKey("msg:processed:" + messageId)) {
            LOGGER.warn("消息已处理：{}", messageId);
            return;
        }
        
        // 使用事务或 Lua 脚本保证原子性
        Boolean executed = redisTemplate.execute(
            new DefaultRedisScript<>(
                "if redis.call('setnx', KEYS[1], ARGV[1]) == 1 then " +
                "  redis.call('expire', KEYS[1], 86400) " +
                "  return 1 " +
                "else " +
                "  return 0 " +
                "end",
                Long.class
            ),
            Collections.singletonList("msg:processed:" + messageId),
            message.getOrderId()
        );
        
        if (executed == 1) {
            // 处理消息
            processOrder(message);
        }
    }
}
```

## 12.7 异步任务监控

### 12.7.1 任务状态监控

```java
@Component
public class TaskMonitor {
    
    @Autowired
    private ThreadPoolTaskExecutor taskExecutor;
    
    /**
     * 获取任务执行状态
     */
    public Map<String, Object> getTaskStatus() {
        Map<String, Object> status = new HashMap<>();
        
        status.put("corePoolSize", taskExecutor.getCorePoolSize());
        status.put("maxPoolSize", taskExecutor.getMaxPoolSize());
        status.put("poolSize", taskExecutor.getPoolSize());
        status.put("activeCount", taskExecutor.getActiveCount());
        status.put("queueCapacity", taskExecutor.getQueueCapacity());
        status.put("queueSize", taskExecutor.getQueue().size());
        status.put("completedTaskCount", taskExecutor.getCompletedTaskCount());
        status.put("rejectedTaskCount", taskExecutor.getRejectedExecutionHandler());
        
        return status;
    }
}
```

### 12.7.2 告警规则

| 指标 | 警告阈值 | 严重阈值 |
|------|---------|---------|
| 队列大小 | > 50 | > 100 |
| 活跃线程 | > 80% | > 95% |
| 拒绝任务 | > 0 | > 10 |
| 任务耗时 | > 5s | > 30s |

## 12.8 最佳实践

### 12.8.1 异步任务

1. **任务拆分**：大任务拆分为小任务并行执行
2. **超时控制**：设置合理的超时时间
3. **异常处理**：异步任务内部必须捕获异常
4. **资源隔离**：不同业务使用不同线程池
5. **监控告警**：实时监控任务执行情况

### 12.8.2 定时任务

1. **避免重叠**：使用分布式锁防止重复执行
2. **错过执行**：配置合理的 misfire 策略
3. **任务监控**：记录每次执行结果
4. **动态管理**：支持运行时增删改任务

### 12.8.3 消息队列

1. **消息确认**：使用手动确认保证可靠性
2. **幂等处理**：消费者必须幂等
3. **死信队列**：处理失败消息
4. **监控告警**：监控队列积压情况
