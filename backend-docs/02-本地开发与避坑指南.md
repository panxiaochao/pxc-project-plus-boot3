## 2.3 环境搭建步骤

### 2.3.1 克隆项目

```bash
git clone https://github.com/panxiaochao/pxc-project-plus-boot3.git
cd pxc-project-plus-boot3
```

### 2.3.2 初始化数据库

```bash
# 解压最新 SQL 脚本
unzip script.sql/pxc-system-plus-20260309.sql.zip

# 执行 SQL 脚本（需先创建数据库）
mysql -h 127.0.0.1 -P 3308 -u root -p -e "CREATE DATABASE IF NOT EXISTS `pxc-system-plus` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
mysql -h 127.0.0.1 -P 3308 -u root -p pxc-system-plus < pxc-system-plus-20260309.sql
```

### 2.3.3 启动 Redis

```bash
# macOS (使用 Homebrew)
brew install redis
brew services start redis

# 或使用 Docker
docker run -d -p 6379:6379 --name redis redis:7-alpine
```

### 2.3.4 配置 application.yml

```bash
# 编辑配置文件
vim pxc-application-starter/src/main/resources/application.yml
```

**关键配置项：**

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3308/pxc-system-plus?...
    username: root
    password: YOUR_PASSWORD  # 修改为你的数据库密码
  data:
    redis:
      host: 127.0.0.1
      port: 6379
      # password: YOUR_REDIS_PASSWORD  # 如有密码请取消注释

# Sa-Token 配置
sa-token:
  jwt-secret-key: YOUR_JWT_SECRET  # 生产环境请修改
```

## 2.4 编译与启动

### 2.4.1 编译项目

```bash
# 根目录编译
mvn clean compile -DskipTests

# 或编译指定模块
mvn clean compile -DskipTests -pl pxc-biz/pxc-biz-system -am
```

### 2.4.2 启动应用

**方式一：Maven 命令**

```bash
cd pxc-application-starter
mvn spring-boot:run
```

**方式二：IDEA 直接运行**

1. 打开 `pxc-application-starter/src/main/java/io/github/panxiaochao/project/ProjectSystemApplication.java`
2. 点击运行按钮或 `Shift+F10`

**方式三：打包后运行**

```bash
# 打包
mvn clean package -DskipTests

# 运行
java -jar pxc-application-starter/target/pxc-application-starter.jar
```

## 2.6 常见报错与解决方案

### 2.6.1 数据库连接失败

**报错信息：**
```
Caused by: com.mysql.cj.jdbc.exceptions.CommunicationsException: 
Communications link failure
```

**解决方案：**
1. 检查 MySQL 服务是否启动：`mysql.server status` 或 `brew services list`
2. 检查端口是否被占用：`lsof -i :3308`
3. 确认数据库已创建：`mysql -u root -p -e "SHOW DATABASES;"`
4. 检查配置文件中的数据库地址、端口、用户名密码

---

### 2.6.2 Redis 连接失败

**报错信息：**
```
Caused by: io.lettuce.core.RedisConnectionException: 
Unable to connect to 127.0.0.1:6379
```

**解决方案：**
1. 检查 Redis 服务：`redis-cli ping` 应返回 `PONG`
2. 启动 Redis：`brew services start redis`
3. 检查端口：`lsof -i :6379`

---

### 2.6.3 端口占用

**报错信息：**
```
Port 8081 is already in use
```

**解决方案：**

```bash
# 查找占用进程
lsof -i :8081

# 杀死进程
kill -9 <PID>

# 或修改配置使用其他端口
vim pxc-application-starter/src/main/resources/application.yml
# server.port: 8082
```

---

### 2.6.4 Lombok 编译报错

**报错信息：**
```
cannot find symbol @Data
```

**解决方案：**
1. 安装 Lombok 插件
2. IDEA 设置中启用注解处理：
   - `Settings → Build, Execution, Deployment → Compiler → Annotation Processors`
   - 勾选 "Enable annotation processing"

---

### 2.6.5 MapStruct 转换类找不到

**报错信息：**
```
Cannot find symbol: ISysUserDTOConvert.INSTANCE
```

**解决方案：**
1. 清理并重新编译：`mvn clean compile -DskipTests`
2. 检查 target 目录是否生成了实现类：
   - `target/generated-sources/annotations/...`
3. 确保 IDE 识别了生成的源码

---

### 2.6.6 Sa-Token 认证失败

**报错信息：**
```
Not Login: 301
```

**解决方案：**
1. 检查请求头是否携带 Token：`Authorization: Bearer <token>`
2. 确认接口不在白名单中（见 `application.yml` 的 `sa-token-plus.white-urls`）
3. 使用登录接口获取 Token：
   ```bash
   POST /auth/v1/login
   {
     "username": "admin",
     "password": "admin123"
   }
   ```

---

### 2.6.7 依赖下载缓慢

**解决方案：**

**使用阿里云 Maven 镜像：**

```xml
<!-- 在 ~/.m2/settings.xml 中添加 -->
<mirrors>
  <mirror>
    <id>aliyun-maven</id>
    <mirrorOf>central</mirrorOf>
    <name>阿里云公共仓库</name>
    <url>https://maven.aliyun.com/repository/public</url>
  </mirror>
</mirrors>
```

## 2.7 开发调试技巧

### 2.7.1 开启 SQL 日志

配置文件已默认开启：

```yaml
mybatis-plus:
  configuration:
    log-impl: org.apache.ibatis.logging.slf4j.Slf4jImpl
```

日志输出在 IDEA 控制台，查看完整 SQL 与参数绑定。

---

### 2.7.2 热部署（可选）

添加 `spring-boot-devtools` 依赖：

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-devtools</artifactId>
    <scope>runtime</scope>
    <optional>true</optional>
</dependency>
```

IDEA 设置：
- `Settings → Build, Execution, Deployment → Compiler` → 勾选 "Build project automatically"
- `Settings → Advanced Settings` → 勾选 "Allow auto-make to start even if developed application is currently running"

---

# 运行所有测试
mvn test

mvn test -Dtest=PxcMybatisPlusGeneratorTest

mvn test -pl pxc-module/pxc-generator-code
