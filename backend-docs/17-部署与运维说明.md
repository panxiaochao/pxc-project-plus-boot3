## 17.2 应用打包

### 17.2.1 Maven 打包

```bash
# 编译打包
mvn clean package -DskipTests

# 生成产物
# target/pxc-application-starter.jar
```

### 17.2.2 启动脚本

**启动：**
```bash
#!/bin/bash
APP_NAME=pxc-application-starter.jar
APP_DIR=/opt/project-system

cd $APP_DIR

# 启动应用
nohup java -jar \
  -Xms2g \
  -Xmx2g \
  -XX:+UseG1GC \
  -XX:MaxGCPauseMillis=200 \
  -Dspring.profiles.active=prod \
  $APP_NAME > app.log 2>&1 &

echo "Application started, PID: $!"
```

**停止：**
```bash
#!/bin/bash
APP_NAME=pxc-application-starter.jar

# 查找进程
PID=$(ps -ef | grep $APP_NAME | grep -v grep | awk '{print $2}')

if [ -n "$PID" ]; then
    echo "Stopping application, PID: $PID"
    kill -15 $PID
    
    # 等待 30 秒，如果未停止则强制杀死
    for i in {1..30}; do
        if ! ps -p $PID > /dev/null; then
            echo "Application stopped successfully"
            break
        fi
        sleep 1
    done
    
    # 强制杀死
    if ps -p $PID > /dev/null; then
        echo "Force killing application"
        kill -9 $PID
    fi
else
    echo "Application not running"
fi
```

**重启：**
```bash
./stop.sh && sleep 5 && ./start.sh
```

## 17.3 Docker 部署

### 17.3.1 Dockerfile

```dockerfile
# 基础镜像
FROM openjdk:17-jdk-slim

# 维护者
LABEL maintainer="lypxc@example.com"

# 工作目录
WORKDIR /app

# 复制应用
COPY target/pxc-application-starter.jar app.jar

# 复制配置文件
COPY src/main/resources/application.yml application.yml

# 时区设置
ENV TZ=Asia/Shanghai
RUN ln -snf /usr/share/zoneinfo/$TZ /etc/localtime && echo $TZ > /etc/timezone

# JVM 参数
ENV JAVA_OPTS="-Xms1g -Xmx1g -XX:+UseG1GC -XX:MaxGCPauseMillis=200"

# 暴露端口
EXPOSE 8081

# 健康检查
HEALTHCHECK --interval=30s --timeout=3s --start-period=60s --retries=3 \
  CMD curl -f http://localhost:8081/actuator/health || exit 1

# 启动命令
ENTRYPOINT ["sh", "-c", "java $JAVA_OPTS -jar app.jar"]
```

### 17.3.2 Docker Compose

```yaml
version: '3.8'

services:
  mysql:
    image: mysql:8.0
    container_name: project-system-mysql
    environment:
      MYSQL_ROOT_PASSWORD: root123
      MYSQL_DATABASE: pxc-system-plus
    ports:
      - "3308:3306"
    volumes:
      - mysql-data:/var/lib/mysql
      - ./script.sql:/docker-entrypoint-initdb.d
    networks:
      - project-network
    restart: always

  redis:
    image: redis:7-alpine
    container_name: project-system-redis
    ports:
      - "6379:6379"
    volumes:
      - redis-data:/data
    networks:
      - project-network
    restart: always

  app:
    build: .
    container_name: project-system-app
    depends_on:
      - mysql
      - redis
    environment:
      SPRING_DATASOURCE_URL: jdbc:mysql://mysql:3306/pxc-system-plus
      SPRING_DATASOURCE_USERNAME: root
      SPRING_DATASOURCE_PASSWORD: root123
      SPRING_DATA_REDIS_HOST: redis
      SPRING_DATA_REDIS_PORT: 6379
    ports:
      - "8081:8081"
    networks:
      - project-network
    restart: always
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8081/actuator/health"]
      interval: 30s
      timeout: 3s
      retries: 3

volumes:
  mysql-data:
  redis-data:

networks:
  project-network:
    driver: bridge
```

### 17.3.3  Docker 命令

# 查看日志

## 17.4 K8s 部署（可选）

### 17.4.1 Deployment

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: project-system
  namespace: default
spec:
  replicas: 3
  selector:
    matchLabels:
      app: project-system
  template:
    metadata:
      labels:
        app: project-system
    spec:
      containers:
      - name: project-system
        image: registry.example.com/project-system:1.0
        ports:
        - containerPort: 8081
        env:
        - name: SPRING_DATASOURCE_URL
          value: jdbc:mysql://mysql-service:3306/pxc-system-plus
        - name: SPRING_DATASOURCE_USERNAME
          value: root
        - name: SPRING_DATASOURCE_PASSWORD
          valueFrom:
            secretKeyRef:
              name: db-secret
              key: password
        - name: SPRING_DATA_REDIS_HOST
          value: redis-service
        resources:
          requests:
            memory: "1Gi"
            cpu: "500m"
          limits:
            memory: "2Gi"
            cpu: "1000m"
        livenessProbe:
          httpGet:
            path: /actuator/health
            port: 8081
          initialDelaySeconds: 60
          periodSeconds: 10
        readinessProbe:
          httpGet:
            path: /actuator/health
            port: 8081
          initialDelaySeconds: 30
          periodSeconds: 5
```

## 17.5 CI/CD 流程

### 17.5.1 GitHub Actions

```yaml
# .github/workflows/ci.yml
name: CI/CD Pipeline

on:
  push:
    branches: [ main, develop ]
  pull_request:
    branches: [ main ]

jobs:
  build:
    runs-on: ubuntu-latest
    
    steps:
    - uses: actions/checkout@v3
    
    - name: Set up JDK 17
      uses: actions/setup-java@v3
      with:
        java-version: '17'
        distribution: 'temurin'
    
    - name: Cache Maven packages
      uses: actions/cache@v3
      with:
        path: ~/.m2
        key: ${{ runner.os }}-maven-${{ hashFiles('**/pom.xml') }}
        restore-keys: |
          ${{ runner.os }}-maven-
    
    - name: Build with Maven
      run: mvn clean package -DskipTests
    
    - name: Run Tests
      run: mvn test
    
    - name: Upload artifact
      uses: actions/upload-artifact@v3
      with:
        name: application
        path: pxc-application-starter/target/*.jar

  deploy:
    needs: build
    runs-on: ubuntu-latest
    if: github.ref == 'refs/heads/main'
    
    steps:
    - name: Deploy to production
      run: |
        echo "Deploying to production..."
        # 添加部署脚本
```

### 17.5.2 发布流程

```
开发分支 (develop)
    │
    ▼
代码提交 → CI 构建 → 单元测试 → 代码扫描
    │
    ▼
测试环境部署 → 功能测试 → 性能测试
    │
    ▼
预发环境部署 → 回归测试 → 验收测试
    │
    ▼
生产环境部署 → 健康检查 → 灰度发布
```

## 17.8 备份与恢复

### 17.8.1 数据库备份

**定时备份脚本：**

```bash
#!/bin/bash
# backup.sh

BACKUP_DIR=/backup/mysql
DATE=$(date +%Y%m%d_%H%M%S)
DB_NAME=pxc-system-plus

# 创建备份目录
mkdir -p $BACKUP_DIR

# 执行备份
mysqldump -h localhost -u root -p'password' \
  --single-transaction \
  --routines \
  --triggers \
  $DB_NAME > $BACKUP_DIR/${DB_NAME}_${DATE}.sql

# 压缩备份
gzip $BACKUP_DIR/${DB_NAME}_${DATE}.sql

# 删除 30 天前的备份
find $BACKUP_DIR -name "*.sql.gz" -mtime +30 -delete

echo "Backup completed: ${DB_NAME}_${DATE}.sql.gz"
```

**定时任务：**
```bash
# crontab -e
0 2 * * * /opt/scripts/backup.sh
```

### 17.8.2 数据恢复

```bash
# 解压备份文件
gunzip pxc-system-plus_20260421_020000.sql.gz

# 恢复数据
mysql -h localhost -u root -p pxc-system-plus < pxc-system-plus_20260421_020000.sql
```

## 17.9 运维监控

### 17.9.1 监控面板

**关键指标：**
- 应用状态（UP/DOWN）
- JVM 内存/CPU 使用率
- 数据库连接数
- Redis 命中率
- HTTP 请求量/响应时间

### 17.9.2 告警配置

```yaml
# Prometheus 告警规则
groups:
- name: project-system
  rules:
  - alert: HighErrorRate
    expr: rate(http_server_requests_seconds_count{status="500"}[5m]) > 0.01
    for: 5m
    labels:
      severity: warning
    annotations:
      summary: "高错误率"
      
  - alert: HighResponseTime
    expr: histogram_quantile(0.99, rate(http_server_requests_seconds_bucket[5m])) > 1
    for: 5m
    labels:
      severity: critical
    annotations:
      summary: "响应时间过长"
```

## 17.10 故障排查

### 17.10.1 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 应用启动失败 | 端口占用 | 检查端口释放 |
| 数据库连接失败 | 配置错误 | 检查连接字符串 |
| Redis 连接失败 | 网络不通 | 检查防火墙 |
| OOM 错误 | 内存不足 | 增加内存/优化代码 |
| 慢查询 | 索引缺失 | 添加索引 |

### 17.10.2 诊断命令

```bash
# 查看进程
ps -ef | grep java

# 查看端口占用
netstat -tlnp | grep 8081

# 查看日志
tail -f logs/app.log

# 查看线程栈
jstack <PID>

# 查看堆内存
jmap -heap <PID>

# 查看 GC 情况
jstat -gc <PID> 1000 10
```
