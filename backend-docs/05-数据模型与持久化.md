  sql-log-trace: true
  global-config:
    banner: false

### 5.4.2 自动填充配置

通过 `@TableField(fill = FieldFill.XXX)` 实现自动填充：

```java
// 创建时填充
@TableField(fill = FieldFill.INSERT)
private Integer createBy;

// 创建和更新时填充
@TableField(fill = FieldFill.INSERT_UPDATE)
private Integer updateBy;

// 创建时填充时间
@TableField(fill = FieldFill.INSERT)
private LocalDateTime createAt;

// 创建和更新时填充时间
@TableField(fill = FieldFill.INSERT_UPDATE)
private LocalDateTime updateAt;
```

## 5.5 查询示例

### 5.5.1 分页查询（联表）

**代码位置：** `SysUserServiceImpl.java:51-64`

```java
@Override
public List<SysUserQueryVO> page(Pagination pagination, SysUserPageQueryDTO pageQueryDTO) {
    MPJLambdaWrapper<SysUserPO> wrapper = new MPJLambdaWrapper<>();
    wrapper.selectAll(SysUserPO.class)
        .selectAs(SysPostPO::getPostCode, SysUserQueryVO::getPostCode)
        .leftJoin(SysUserPostPO.class, SysUserPostPO::getUserId, SysUserPO::getId)
        .leftJoin(SysPostPO.class, SysPostPO::getId, SysUserPostPO::getPostId);
    
    // 条件查询
    this.mbjLambdaQuery(wrapper, pageQueryDTO);
    
    // 分页查询
    IPage<SysUserQueryVO> page = sysUserMapper
        .selectJoinPage(Page.of(pagination.getPageNo(), pagination.getPageSize()), 
                       SysUserQueryVO.class, wrapper);
    pagination.setTotal(page.getTotal());
    return page.getRecords();
}
```

## 5.7 性能优化建议

### 5.7.1 查询优化

1. **避免 N+1 查询**：使用 `MPJLambdaWrapper` 联表查询
2. **分页查询限制**：单页最大 100 条
3. **索引覆盖**：查询字段尽量命中索引
4. **慢查询日志**：开启 MySQL 慢查询日志

### 5.7.2 缓存策略

1. **字典数据**：Redis 缓存，TTL 30 分钟
2. **菜单数据**：本地 Caffeine 缓存
3. **用户信息**：Redis 缓存，TTL 2 小时

### 5.7.3 潜在瓶颈

| 场景 | 风险 | 建议 |
|------|------|------|
| 用户分页查询 | 联表多，性能差 | 添加组合索引 |
| 菜单树查询 | 递归深度大 | 缓存完整树结构 |
| 日志表增长 | 数据量大 | 分区表/定期归档 |
